# پروژه وب‌سایت شهر قالپاق (Shahr Ghalpaq)

این پروژه یک وب‌سایت «صفحه فرود» (Landing Page) مدرن و کاملاً ریسپانسیو برای فروشگاه لوازم جانبی خودرو «شهر قالپاق» است. این سایت با تمرکز بر اصول مدرن طراحی وب و معماری اصولی کدنویسی توسعه داده شده است.

## 🚀 دمو آنلاین

مشاهده سایت: [https://fm6739.github.io/shahrghalpaq/](https://fm6739.github.io/shahrghalpaq/)

## 🛠 تکنولوژی‌های استفاده شده

این پروژه با رویکرد "Desktop-First" طراحی شده و از ابزارهای زیر استفاده می‌کند:

- **HTML5**: ساختار معنایی و اصولی.
- **CSS3 / Sass (SCSS)**: مدیریت استایل‌ها با معماری پیشرفته **7-1**.
- **BEM (Block Element Modifier)**: متدولوژی نام‌گذاری دقیق کلاس‌ها برای نگهداری راحت‌تر کدها.
- **Responsive Design**: کاملاً سازگار با موبایل، تبلت و دسکتاپ.
- **Animations**: استفاده از انیمیشن‌های CSS برای افزایش تجربه کاربری (UX).

## 📂 ساختار پروژه (Sass 7-1 Architecture)

پروژه بر اساس معماری استاندارد ناتورز سازماندهی شده است:

- `base/`: تنظیمات پایه، تایپوگرافی و انیمیشن‌ها.
- `components/`: اجزای قابل استفاده مجدد مثل دکمه‌ها، فرم‌ها و کارت‌ها.
- `layout/`: ساختار اصلی صفحات مثل هدر، فوتر و گرید سیستم.
- `pages/`: استایل‌های اختصاصی صفحات.

## 💡 اهداف پروژه

هدف اصلی از ساخت این پروژه، تمرین عملی اصول پیشرفته CSS، تسلط بر پیش‌پردازنده Sass و پیاده‌سازی یک وب‌سایت تجاری واقعی با استاندارد بالا بوده است.
